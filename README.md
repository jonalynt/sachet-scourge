# <h1 align="center"> Sachet Scourge: Philippines Plastic Crisis </h1>

**Understanding the Single-Use Plastic Crisis in the Philippines**

*Every day, 163 million plastic sachets flood the Philippines.*  
This advocacy website educates on the sachet scourge, its causes, impacts, solutions, and calls to action.

## 🎯 Project Purpose

**Academic project & portfolio showcase** demonstrating:
- Web development skills (responsive design, JS interactivity)
- Data visualization (waste stats, projections)
- UX design for advocacy (clear CTAs, mobile-first)

**Target audience**: Filipino students, communities, environmental advocates in Iloilo/Western Visayas.

---

## 📊 Key Content Highlights

| Section | Key Stats & Features |
|---------|---------------------|
| **Crisis Scale** | 163M sachets/day, 20% to oceans, 95% growth by 2040 |
| **Impacts** | 100K+ marine deaths/year, microplastics in 90% salt |
| **Solutions** | Refill systems (201% savings), EPR laws, biodegradable packaging |
| **Success Stories** | Siquijor 58% diversion, Greenpeace 50K sachets avoided |
| **Take Action** | Zero-waste links, volunteer opportunities, RA 9003 info |
